# 0002. 빈칸 비율과 단계 통과 규칙

- 상태: 확정 (실기기에서 써 보고 어려우면 조정)
- 날짜: 2026-10-01 (Phase 1 구현)

## 결정

1. **단계별 빈칸 비율**: 1단계 10%, 2단계 27.5%, 3단계 45%, 4단계 62.5%, 5단계 80%. 1단계와 5단계는 `docs/spec.md`의 확정값이고, 사이는 같은 간격(선형)으로 정했다. 비율은 문장별이 아니라 지문 전체의 단어 수 기준이며 반올림하고 최소 1개다.
2. **빈칸 선택**: 단어마다 (내용어 우선, 지문 시드 난수) 순위를 매겨 앞에서부터 비율만큼 비운다. 순위는 단계와 무관하므로 낮은 단계의 빈칸은 높은 단계에도 항상 포함된다. 기능어(관사·전치사·접속사·대명사·be/do/have 동사 등, `lib/cloze/index.ts`의 목록)는 내용어를 모두 비운 뒤에야 비워진다. 시드는 지문 id(`passage-<id>`)다. 글자가 한 개뿐인 토큰((A)·(B) 표지, a, I)은 빈칸 후보에서 제외하고, 비율의 분모도 후보 수다.
3. **모드는 단계와 별개**: 힌트 없음·첫글자·직접 타이핑은 같은 빈칸에 보여 주는 방식만 다르다. 문장 순서 맞추기는 단계와 무관하다.
4. **통과 규칙**: 힌트 없음·첫글자는 정답을 확인한 뒤 사용자가 스스로 "다 맞혔다"를 눌러 통과를 기록한다(자기 확인). 직접 타이핑은 모든 빈칸이 맞아야 자동으로 통과를 기록한다. 대소문자, 곡선/직선 따옴표, 앞뒤 문장부호는 무시하고 철자는 정확해야 한다. 문장 순서 맞추기는 채점은 하지만 연습용이라 통과 단계를 기록하지 않는다.
5. **기록**: `review` 테이블에 `item_type='passage'`로 통과한 가장 높은 단계를 저장하고, 낮은 단계를 다시 통과해도 낮추지 않는다(`MAX`). `next_due`는 Phase 3의 복습 일정 구현 전까지 비워 둔다.
6. **문장 교정 저장**: `UNIQUE(passage_id, ord)` 때문에 문장을 지우고 다시 넣는다. 영어 문장이 그대로인 문장의 해석·메모와 그 문장을 가리키던 단어(`vocab.sentence_id`)는 새 행으로 이어 주고, 고치거나 합친 문장의 해석·메모는 비워진다.

## 이유와 기각한 대안

- 선형 간격: 단순하고 단계가 오를수록 균등하게 어려워진다. 기각: 앞쪽을 촘촘하게 하는 비선형(근거 없는 가정이 늘어남).
- 지문 전체 기준 비율: 짧은 문장에서 반올림 편차가 커지는 것을 피함.
- 순위 고정(단계 간 포함 관계): 3단계를 통과한 뒤 4단계에서 같은 빈칸이 다시 나오므로 "더 채워진다"는 느낌이 일관됨. 기각: 단계마다 새로 무작위(같은 지문 반복 학습의 일관성이 떨어짐).
- 자기 확인: 빈칸에 입력하지 않는 모드는 앱이 정답 여부를 알 수 없다. 기각: 이 모드들을 통과 기록에서 제외(5단계까지 통과를 기록할 방법이 타이핑뿐이 됨).
- 순서 맞추기 미기록: 단계(빈칸 비율)와 무관한 연습이라 `review.level`의 의미를 흐리지 않기 위함.
