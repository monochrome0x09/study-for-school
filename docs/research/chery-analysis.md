## 개요

- Chery: MISE가 만든 중고등 내신 앱.
- 영어 학습 흐름: 본문 분석 → 5단계 빈칸 암기 → 문제 풀이 → 단원 평가.
- 부가 기능: 단어장, 맞춤 시험지, my 지문.
