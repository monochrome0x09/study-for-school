# 원자료 폴더

사용자가 지문 입력용으로 제공한 원자료(시험지, 교재 스캔 등)를 두는 곳입니다.

## 규칙

- 실제 원자료 파일은 `docs/sources/private/`에만 두며, 이 폴더는 `.gitignore`로 제외되어 커밋·푸시되지 않습니다. 이 저장소는 공개이고 `PROJECT.md`의 콘텐츠 정책이 본문·문제를 저장소에 넣지 않도록 하기 때문입니다.
- 지문 내용(영문·해석·필기)은 이 README, 다른 문서, 테스트, 커밋 메시지에 옮기지 않습니다. 파일의 종류와 범위만 아래 목록에 적습니다.
- 지문은 앱에서 사용자가 기기에 직접 등록합니다.
- 클라우드 작업 환경은 비활성 시 회수되므로 `private/`의 파일은 사라질 수 있습니다. 원본은 사용자가 따로 보관해야 합니다.
