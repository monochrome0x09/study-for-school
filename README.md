# 내신 영어 학습 앱 기획서

Oct 2, 2026 · @만월

이 앱은 나 혼자 쓰는 iPhone 앱으로, NE능률 고2 영어 2 교과서와 고2 학력평가(듣기 제외) 지문을 '붙여넣기 → 본문 분석 → 5단계 빈칸 암기 → 단어장' 순서로 학습하게 하며, 첫 버전은 1\~2일 안에 만들고 남은 약 13일은 직접 쓰면서 지문을 채웁니다.

## Chery 분석

Chery는 MISE가 만든 중고등 내신 앱으로, 2021년 7월 출시 후 누적 다운로드 139만 건 이상, 문제은행 98만 문항을 내세우며 영어는 '본문 분석 → 암기 → 문제 풀이 → 단원 평가' 4단계로 구성됩니다. 아래 수치는 공식 사이트와 스토어 표기 기준이며, 가격은 2023년 10월 기준 자료라 현재와 다를 수 있습니다.

| 항목 | 확인한 내용 |
| --- | --- |
| 대상 | 중·고등학생, 국어·수학·영어·사회·과학·역사 전과목 (원래는 고등 영어 내신 앱) |
| 영어 1단계 본문 분석 | 교과서·부교과서 78종의 해석, 핵심 단어, 기출 포인트 |
| 영어 2단계 본문 암기 | 5단계 난이도의 빈칸 채우기로 지문 암기 |

초기 앱 이름이 '수능/내신영어-CHERY'였고 교과서 32종·수능 기출·평가원 모의고사를 제공했다는 점에서, 영어 모의고사와 교과서에서 출발한 구조가 지금 계획과 같은 방향입니다.

## 빈틈과 방향

Chery의 가장 큰 빈틈은 '영어 본문을 사용자가 직접 입력해야 한다'는 점이며, 우리 앱은 지문 입력을 쉽게 만들고 암기·복습 방식을 더 다양하게 하는 쪽에서 승부합니다.

| 확인된 불편 (출처) | 우리 앱의 대응 |
| --- | --- |
| 유료인데도 영어 본문이 없어 직접 입력해야 하고, 학교와 내용이 다름 (App Store 리뷰, 2025.10) | iPhone 사진 속 글자를 복사해 붙여넣고 문장 단위 교정 화면에서 바로잡기 |
| 빈칸 학습에 맨 앞글자 없이 완전히 비운 모드가 없음 (리뷰, 2025.09) | 힘트 없음 / 첫글자 / 직접 타이핑 / 문장 순서 맞추기 모드 추가 |
| 필기가 가끔 사라지고 필기 중 확대가 안 됨 (리뷰, 2025.10) | 1단계에서는 필기 기능을 넣지 않음 |
| 한 유형 문제가 자주 나오고 풀이가 없는 문항이 있음 (나무위키) | 문제 풀이는 이번 계획에서 제외하고, 넣게 되면 모든 문항에 해설 필수 |
| 월 19,900원부터의 구독제 (나무위키, 2023.10) | 영어 한 과목에 집중해 가벼운 기능 중심으로 시작 |

현재 Chery 스토어 설명에는 평가원 모의고사 학습이 따로 소개되지 않고 실물 '봉투모의고사'만 보이므로, 학력평가 지문을 정식 학습 대상으로 두는 것이 차별점이 될 수 있습니다.

## 학습 흐름

지문 하나를 '등록 → 분석 → 암기 → 복습' 순으로 돌리며, 교과서와 학력평가는 시작 화면만 다릅니다.

**교과서 (NE능률 고2 영어 2)**

1. Lesson을 고르고 시험일을 입력합니다.
2. 지문을 붙여넣고 문장 단위로 교정합니다.
3. JEV로 해석·어휘 초안을 만들고 내가 고칩니다.
4. 빈칸 암기를 1단계부터 5단계까지 통과합니다.
5. 10월 8일, 12일, 14일(시험 7일·3일·1일 전)에 지문과 단어를 다시 암기합니다.

**학력평가 (듣기 제외, 샘플: 2025 고2 9월)**

1. 회차를 만들고 독해 문항 번호별로 지문을 붙여넣습니다.
2. 샘플 지문 1개로 분석과 암기를 끝까지 돌려 앱을 검증합니다.
3. 검증이 끝나면 나머지 번호의 지문을 추가하고 같은 흐름으로 학습합니다.

## 데이터와 콘텐츠

지문을 중심에 두고 문장, 단어, 문제, 학습 기록이 지문에 매달리는 5개 테이블로 충분하며, 본문·문제를 앱에 미리 넣어 배포하지 않는 것이 초기 저작권 위험을 피하는 가장 확실한 방법입니다.

| 테이블 | 핵심 필드 | 역할 |
| --- | --- | --- |
| passage | id, subject(영어 기본), track(교과서/학평), 출처 메타(학교·교과서·단원 또는 연도·월·문항 번호), 원문 | 학습의 단위 |
| sentence | passage\_id, order, en, ko, note | 빈칸 생성·순서 맞추기의 단위 |
| vocab | word, meaning, passage\_id, sentence\_id | 단어장·어휘 문제 |
| question | passage\_id, type, stem, choices, answer, explanation, tag | 문제 풀이·채점 — 이번 계획에서 제외 |
| review | user\_id, item\_type, item\_id, level(1\~5), next\_due | 암기 단계와 복습 일정 |

콘텐츠 확보는 다음 순서를 제안합니다.

1. 1단계: 사용자가 직접 등록한 지문만 처리하고 자신의 기기에만 저장합니다. 내 공부용이라면 가장 안전합니다.
2. 2단계: AI가 해석·어휘 초안을 만들되, 정답과 해설은 사용자가 검수해 확정합니다. AI가 만든 정답은 틀릴 수 있습니다.
3. 3단계: 이 앱을 타인에게 공개하거나 판매할 경우, 교과서 출판사와 시험 출제 기관의 이용 조건을 미리 확인해야 합니다. 이 부분은 법률 자문이 아니므로 실제 출시 전에 확인이 필요합니다.

## 기술 구성

서버 없이 iPhone 앱 하나와 기기 내 저장소만으로 만들고, AI는 보유한 JEV API만 앱에서 직접 호출합니다.

| 계층 | 선택 | 이유 |
| --- | --- | --- |
| 앱 | React Native(Expo) + TypeScript, iPhone에서 Expo Go로 실행 | 배포 없이 내 iPhone에서 바로 실행하고 수정할 수 있어 1\~2일 일정에 맞음 |
| 저장소 | 기기 내 SQLite(expo-sqlite) | 5개 테이블을 그대로 쓰고 오프라인에서도 동작 |
| 지문 입력 | 붙여넣기 + iPhone 사진 텍스트 복사 | 네이티브 OCR 모듈은 Expo Go에서 쓰기 어려워 개발 시간을 아끼려고 제외 |
| 문장 분할 | 규칙 기반(마침표, 약어 예외) + 내가 교정 | 정확한 문장 단위가 빈칸 생성의 기반 |
| 빈칸 생성 | 단계별 빈칸 비율(1단계 10% → 5단계 80% 안), 내용어 우선, 지문별 고정 시드 | 같은 지문은 같은 빈칸이 나와야 반복 암기가 됨 |
| 복습 일정 | 시험일(10월 15일) 기준 7일 전·3일 전·1일 전(10월 8·12·14일) | 13일 안에 끝나는 일정에는 단순한 방식이 맞음 |
| AI | JEV API로 문장별 해석·핵심 어휘를 JSON으로 받아 SQLite에 저장 | 한 번 받은 결과를 재사용해 호출 수를 줄이고, 오류는 내가 직접 고침 |
| API 키 | 앱 설정 화면에서 입력해 기기에만 저장 | 코드에 키를 넣지 않기 위함 |

우회로 연결한 GPT 서버는 성능이 낮다고 하셨으므로 이번 계획에서 쓰지 않습니다.

## 확장 여지 (한국사 등 암기 과목)

지금은 영어만 만들지만, 나중에 암기 과목으로 넓힐 때 구조를 뒤었지 않도록 지금 아래 세 가지만 지킵니다.

- passage 테이블에 subject 필드(기본값 영어)를 두고, 화면 문구에 '영어'를 고정해 쓰지 않습니다.
- 빈칸 암기·D-day·복습 일정은 텍스트가 있으면 어떤 과목에도 쓰이게 만들고, 문장 해석·단어장처럼 영어에만 필요한 기능은 subject가 영어일 때만 보여줍니다.
- 한국사 같은 과목은 나중에 중요 용어를 직접 표시해 가리는 '키워드 빈칸'과 연표 순서 맞추기를 더하면 되고, Chery도 역사 과목에 연표 학습을 두고 있습니다.

## 결정 사항과 남은 확인

- 시험 범위는 NE능률 고2 영어 2의 1과부터 2과까지입니다.
- 시험일은 10월 15일입니다.
- 학평 지문은 복사 가능한 텍스트로 가지고 있고, 샘플은 2025 고2 9월입니다.
